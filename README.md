# 🎓 Student Grade Management System (Java Console Project)

A simple **Java console application** to manage and calculate student grades.  
This program allows users to enter student details, marks, compute averages, assign grades, and display reports — all from the terminal.

---

## 🚀 Features

✅ Add new student records  
✅ Calculate total and average marks  
✅ Assign grades automatically  
✅ Display all student details in tabular format  
✅ Simple and interactive console-based interface  
✅ Beginner-friendly Java project for practice or GitHub portfolio

---

## 🧠 Concepts Used

- Object-Oriented Programming (Classes & Objects)  
- Arrays / ArrayList  
- Loops and Conditional Statements  
- Basic Console Input/Output  
- Simple Data Processing Logic
